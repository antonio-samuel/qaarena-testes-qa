Documentação dos meus testes no [QARENA](https://qarenaqa.vercel.app), um
ambiente de treino gratuito com bugs plantados. Este repositório reúne os
bug reports que escrevi enquanto pratico o ciclo de QA: investigar,
reproduzir e documentar.

> ⚠️ Projeto de estudo. Os testes foram feitos em ambiente de treino,

## Como documento cada bug

Cada report segue a mesma estrutura:
título, pré-condições, passos para reproduzir, resultado atual,
resultado esperado, severidade, prioridade, ambiente e evidências
(prints ou vídeos na pasta `evidencias/`).

## Ambiente de teste

Chrome, Windows, desktop. Dados fictícios fornecidos pelo próprio QARENA.

## O que estou aprendendo

- Escrever passos que outra pessoa consiga reproduzir sem me perguntar nada
- Diferenciar severidade (impacto) de prioridade (urgência)
- Separar resultado atual de resultado esperado
- (adicione aqui conforme avançar)
